🧬 Bacterial Genomics Capstone

Whole Genome Sequencing (WGS) Quality Control Workflow using FastQC, MultiQC, and fastp for quality assessment of Pseudomonas isolates retrieved from the NCBI Sequence Read Archive (SRA).

📖 Project Overview

This repository demonstrates a complete and reproducible Whole Genome Sequencing (WGS) quality-control workflow developed for the Bacterial Genomics Capstone Project. The pipeline starts from downloading sequencing data from the NCBI Sequence Read Archive (SRA), performs comprehensive quality assessment, trims adapters and low-quality bases, and finally generates interactive MultiQC reports for comparative analysis.
